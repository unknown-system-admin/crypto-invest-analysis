# 指標分析系統設計 Spec

## 目標

建立完整分析流程，用來：
1. 測試動能指標能否作為自動交易依據
2. 透過機器學習找出最佳指標

## 架構

```
analyzers/
├── __init__.py
├── momentum_analyzer.py    # 動能指標有效性分析
├── feature_selector.py     # ML 特徵篩選
└── report_generator.py     # 生成分析報告
```

---

## 階段一：動能指標有效性測試

### 1.1 相關性分析

- 計算 `momentum_score` 與未來 N 天報酬的 Pearson 相關係數
- 評估標準：
  - |r| > 0.3：強相關
  - 0.1 < |r| < 0.3：中等相關
  - |r| < 0.1：弱相關

### 1.2 閾值回測

- 測試不同 `buy_threshold` 組合：
  - 保守：0.4 / -0.4
  - 中等：0.3 / -0.3
  - 積極：0.2 / -0.2
- 每組參數計算績效指標

### 1.3 基準比較

- 與 buy-and-hold 策略比較
- 計算超額報酬 (Alpha)

---

## 階段二：ML 指標篩選

### 2.1 特徵準備

- 使用 `feature_engine` 計算 18 個技術指標 + 3 個動量特徵
- 特徵總數：21 個

### 2.2 模型訓練

- 模型：Random Forest Classifier
- 目標：預測未來 5 天漲跌（二分類）
- 訓練/測試分割：80/20

### 2.3 特徵重要性分析

- 輸出 `feature_importances_` 排序
- 識別 Top 10 關鍵指標

### 2.4 相關性矩陣

- 檢查指標間共線性
- 移除高相關（|r| > 0.8）的冗餘指標
